# Kit de lancement CyberSuite

Ce document fournit des textes prêts à adapter. Présente le logiciel honnêtement : c'est un projet éducatif en développement, pas un antivirus ni un outil d'audit professionnel.

## Description courte

CyberSuite réunit quatre petits outils de cybersécurité défensive dans une application Windows en français : contrôle réseau local limité, estimation indicative de robustesse, analyse de journaux et repérage heuristique de phishing.

## Publication courte

J'ai créé CyberSuite : une application Windows en français qui rassemble quatre outils de cybersécurité défensive.

- CyberScanner : vérification TCP limitée sur IP privée/locales.
- PasswordChecker : estimation locale indicative (utilisez uniquement un exemple fictif).
- LogAnalyzer : repérage de motifs dans des journaux locaux.
- PhishingDetector : analyse heuristique de texte et d'URL, sans ouvrir les liens.

Le projet est open source et encore en développement. Les retours constructifs et contributions sont les bienvenus : https://github.com/saku168/CyberSuite
