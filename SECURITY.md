# Sécurité

CyberSuite est un projet éducatif de cybersécurité défensive. Il ne remplace pas un audit professionnel.

## Signaler un problème

Ne publie pas de secret, de mot de passe, de jeton, d'adresse privée ni de données personnelles dans une issue publique. Pour un problème sensible, contacte le mainteneur via les options de contact affichées sur son profil GitHub.

## Périmètre

- CyberScanner effectue uniquement une vérification TCP limitée sur une adresse IP privée ou locale explicitement saisie.
- PhishingDetector analyse du texte sans ouvrir les liens.
- PasswordChecker ne doit jamais recevoir un mot de passe réellement utilisé.
- Les résultats peuvent être incomplets et comporter des faux positifs ou faux négatifs.

Merci de tester uniquement sur des systèmes et des données que tu possèdes ou pour lesquels tu as une autorisation explicite.
