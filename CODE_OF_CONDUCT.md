# Code de conduite

Nous voulons une communauté accueillante, respectueuse et constructive.

- Sois respectueux, patient et bienveillant.
- Critique les idées et le code, jamais les personnes.
- Accueille les débutants et explique les retours de manière utile.
- Pas de harcèlement, d'insultes, de discrimination, de menaces ni de divulgation d'informations privées.
- Garde les contributions dans le cadre de la cybersécurité défensive et légale.

Les mainteneurs peuvent modérer les échanges qui ne respectent pas ces règles.
